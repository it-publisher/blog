**Happy Nomad — набор скиллов для ИИ-агентов, который создаёт гайд по стране прямо из чата экспатов**

В оригинальном приложении Telegram Desktop можно делать экспорты любых чатов не имея прав администратора.

Кидаешь экспорт любого чатика — получаешь готовый структурированный гайд:  
— жильё и районы  
— визы и документы  
— бюджет и цены  
— обмен валюты  
— интернет и связь  
— вотэвер ю нид

Как работает: скрипт режет чат (хоть 20 000+ сообщений) по темам, Клод раскладывает факты по файлам, собирает README и прогоняет фактчек — каждая цифра с датой, устаревшее отсеивается, противоречия помечаются. Никакого «топ-10 городов» из воздуха — только твой чат и живые данные.

В основе — реальный кейс по Аргентине: пайплайн из 5 этапов, обезличивание личных данных и два режима на выходе — публичный гайд или личный план переезда с чеклистом.

Формат — Agent Skills ([SKILL.md](https://skill.md)), так что заводится не только в Claude Code, но и в Codex и других агентах. Двуязычный, EN + RU.

Забрать с Гитхаба:  
[https://github.com/it-publisher/happy-nomad](https://github.com/it-publisher/happy-nomad)

Как пользоваться — всё в README: ставишь скиллы, кидаешь экспорт, даёшь команду.
