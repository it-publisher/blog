**Для осознанности:**

Практика — медитации, дыхательные сессии. Очень удобно, есть медитации на любой случай в жизни, на прогулке, в транспорте, для сна, для пробежки и много других.  
[https://www.praktika.app/ru](https://www.praktika.app/ru)

BreatheWithMe — дыхательные сессии. Новое приложение из силиконовой долины. Очень крутое, моментально возвращает в тело. Таких кислородных приходов я давно не ловил.  
[https://breathewithme.app/](https://breathewithme.app/)

**Для планирования:**

TickTick — для ежедневного планирования, все бытовые дела, идеи, списки в нем.  
[https://ticktick.com/?language=ru_RU](https://ticktick.com/?language=ru_RU)

Расходы OK — простое приложение для ведения бюджета.  
[https://apps.apple.com/ru/app/%D1%80%D0%B0%D1%81%D1%85%D0%BE%D0%B4%D1%8B-%D0%BE%D0%BA-%D1%83%D1%87%D0%B5%D1%82-%D1%80%D0%B0%D1%81%D1%85%D0%BE%D0%B4%D0%BE%D0%B2/id932322041](https://apps.apple.com/ru/app/%D1%80%D0%B0%D1%81%D1%85%D0%BE%D0%B4%D1%8B-%D0%BE%D0%BA-%D1%83%D1%87%D0%B5%D1%82-%D1%80%D0%B0%D1%81%D1%85%D0%BE%D0%B4%D0%BE%D0%B2/id932322041)

[https://play.google.com/store/apps/details?id=biz.mobion.moneyokan&hl=ru&gl=US](https://play.google.com/store/apps/details?id=biz.mobion.moneyokan&hl=ru&gl=US)

Notion — там вообще все: клиенты, рецепты, конспекты, дневники, планы и все остальное. Из страницы в Notion можно легко сделать сайт, чем иногда пользуюсь.  
[https://www.notion.so/](https://www.notion.so/)

Google — весь гугловский пакет, традиционно.  
[https://www.google.ru/intl/ru/docs/about/](https://www.google.ru/intl/ru/docs/about/)

**Для работы:**

Alfred — по сути это поисковик внутри твоего ноута, но функционал там просто запредельный: быстрый запуск приложений, файлов, папок, сценарии использования, быстрая вставка заготовленного текста/кода, адресная книга и хер знает что еще. Маст хэв для продвинутой работы. Платный.  
[https://www.alfredapp.com/](https://www.alfredapp.com/)

Sublime — удобно писать тексты. Ничего не отвлекает, никаких менюшек, только фон, курсор и ты. Можно использовать бесплатно.  
[https://www.sublimetext.com/](https://www.sublimetext.com/)

Pixelmator — нативный фотошоп для макбуков.  
[https://www.pixelmator.com/pro/](https://www.pixelmator.com/pro/)

Reaper — для нарезки подкастов.  
[https://www.reaper.fm/](https://www.reaper.fm/)
